# Security Policy

## Поддерживаемые версии / Supported versions

Актуальная ветка `main` и последний релиз.

## Как сообщить об уязвимости / Reporting a vulnerability

**Не создавайте публичный Issue для уязвимостей.**

Используйте GitHub *Security → Report a vulnerability* (private vulnerability
reporting) в этом репозитории. Если этот канал недоступен — свяжитесь с
владельцем репозитория напрямую через GitHub.

Мы постараемся ответить в разумные сроки и согласовать раскрытие.

## Примечание по данным / Data note

Проект не содержит секретов и учётных данных. Справочники `data/*.json` —
публичные инженерные данные (см. `NOTICE`). Плагин запускает локальный
Python-процесс и не выполняет сетевых запросов наружу.
