# fan-selector — подбор радиальных вентиляторов (ВР 86-77 / ВР 280-46)

Плагин DeepSeek Harness: подбор радиального вентилятора по расходу и давлению —
электродвигатель, дорегулирование и КПД, массо-габаритные характеристики, график
P(Q)/η(Q) и массовый подбор из CSV. Расчёты выполняет Python-ядро
`fan_selector`, которое поставляется **внутри этого пакета**.

## Установка

Понадобится Python 3.11+ с библиотеками `numpy` и `Pillow`:

```bash
pip install numpy pillow
```

Затем добавьте плагин в профиль DSH — через интерфейс (**Профили → установка
плагина → `@rusky_kot/fan-selector`**) или командой:

```bash
dsh plugin --profile <профиль> add @rusky_kot/fan-selector
```

Перезапустите DSH: появится панель «Подбор вентилятора», инструмент агента
`fan_selector_history` и навык `fan-selector`.

Клонировать репозиторий и устанавливать ядро через `pip` не нужно — оно уже в
пакете. Если `python` не в `PATH`, задайте путь переменной `FAN_SELECTOR_PYTHON`.

## Режимы

- дроссельное регулирование (THROTTLE);
- частотное регулирование / ЧРП (VFD);
- сравнение режимов (COMPARE);
- массовый подбор из CSV.
