# Техническое задание
## на разработку подбора радиальных вентиляторов с частотным регулированием (ЧРП)

> **Архив.** Исходное ТЗ реализовано в ядре (`fan_selector/vfd.py`); актуальное описание расчёта — [CALCULATION_VFD.md](../CALCULATION_VFD.md).

---

## 1. Общие сведения

**1.1 Наименование.** Модуль подбора радиальных вентиляторов серий ВР 86-77 и
ВР 280-46 с частотным регулированием (далее — модуль ЧРП).

**1.2 Назначение.** Расширение действующей системы подбора вентиляторов
(проект `fan-selector`) режимом отбора по частоте вращения и подбором
частотного преобразователя: вывод вентилятора в рабочую точку (Q, P) изменением
частоты питающего напряжения, с расчётом требуемой частоты (Гц), оборотов
и подбором конкретной номенклатуры ЧРП.

**1.3 Основание.** Потребность в подборе под конкретный диапазон частоты ЧРП
и формировании комплектной поставки «вентилятор + двигатель + частотник»;
текущее ядро реализует только дроссельный режим.

## 2. Цели и задачи

**Цель.** Обеспечить отбор вентиляторов, выходящих в заданную рабочую точку
при частоте в пределах заданного диапазона, в обе стороны регулирования,
и подобрать к ним реальный частотный преобразователь (по аналогии с двигателем).

**Задачи:**
1. Реализовать расчёт по законам подобия (расход ∝ n, давление ∝ n², мощность ∝ n³).
2. Вычислять требуемую частоту (Гц) и обороты для заданной точки (Q, P).
3. Проверять попадание требуемой частоты в заданный диапазон [f_min, f_max] Гц.
4. Пересчитывать КПД по подобию (смещение точки КПД по расходу).
5. Рассчитывать мощность на валу и потребляемую мощность (без критерия экономии).
6. Подбирать электродвигатель и — по его параметрам — частотный преобразователь.
7. Выдавать результат комплектно: вентилятор → двигатель → ЧРП.
8. Интегрировать результат в существующий JSON-контракт и навык DSH.

## 3. Область применения

Подбор радиальных вентиляторов для систем вентиляции с квадратичной
характеристикой сети. Двигатели — асинхронные (АС) с внешним ЧРП;
EC-двигатели со встроенным регулированием — отдельный режим в перспективе.

## 4. Термины и сокращения

- **ЧРП / VFD** — преобразователь частоты (variable frequency drive).
- **f** — относительная частота, f = f_Гц / f_ном_Гц (f_ном_Гц = 50 Гц).
- **Перекрут** — работа на частоте выше номинальной (f > 1).
- **Кривая сети** — зависимость давления сети от расхода P = k·Q².
- **Законы подобия (affinity laws)** — масштабирование Q, P, N при изменении n.
- **Номенклатура** — каталожное обозначение изделия (двигателя или ЧРП).

## 5. Требования к системе

### 5.1. Функциональные требования

- **ФР-01.** Принимать входной диапазон частоты [f_min_Гц, f_max_Гц].
- **ФР-02.** Для точки (Q_req, P_req) и вентилятора вычислять коэффициент сети
  k = P_req / Q_req².
- **ФР-03.** Находить точку Q₀ пересечения номинальной кривой P_nom(Q) с
  параболой сети k·Q² (численно, скан + бисекция).
- **ФР-04.** Вычислять относительную частоту f = Q_req / Q₀ и требуемую частоту
  f_Гц = f · f_ном_Гц.
- **ФР-05.** Вычислять обороты n = f · n_nom.
- **ФР-06.** Проверять попадание f_Гц в диапазон [f_min_Гц, f_max_Гц]; вне — отказ
  со статусом (FREQ_BELOW_MIN / FREQ_ABOVE_MAX).
- **ФР-07.** Пересчитывать КПД подобием: η_f = η_nom(Q_req / f).
- **ФР-08.** Рассчитывать мощность на валу N_вал = (Q_req/3600)·P_req/η_f.
- **ФР-09.** Рассчитывать потребляемую мощность N_вх = N_вал / (η_ЧРП · η_двиг).
- **ФР-10.** Подбирать электродвигатель по N_вал и оборотам (существующая логика).
- **ФР-11.** Подбирать частотный преобразователь по параметрам двигателя
  (мощность, ток, напряжение) из справочника ЧРП.
- **ФР-12.** Выдавать результат комплектно (раздел 7), включая пару
  «вентилятор → ЧРП».
- **ФР-13.** Поддерживать режимы: дроссельный (по умолчанию) и частотный.
- **ФР-14.** Для режима VFD формировать график с номинальной и приведённой
  (при f) кривой и рабочей точкой.

### 5.2. Требования к расчётному ядру

- Существующий модуль `core.py` **не модифицируется**.
- Расчёт ЧРП реализуется в отдельном модуле `vfd.py` как чистые функции.
- Переиспользуются существующие аппроксимации `fit_curve` и подбор двигателя.
- Подбор ЧРП выполняется **после** подбора двигателя, по его параметрам.

### 5.3. Требования к данным

**5.3.1. Конфигурация** (`config.json`) — блок `vfd`:

```json
"vfd": {
  "f_nom_hz": 50.0,
  "f_min_hz_default": 20.0,
  "f_max_hz_default": 60.0,
  "eta_vfd": 0.97,
  "eta_motor_part_load": 0.85
}
```

**5.3.2. Справочник ЧРП** (`data/vfd.json`) — по аналогии с `motors.json`:

```json
[
  { "model": "ПЧВ-101-1К5-В", "p_kw": 1.5, "i_nom_a": 3.7, "u_in": "380/50", "phase": "3ф" },
  { "model": "ПЧВ-101-2К2-В", "p_kw": 2.2, "i_nom_a": 5.0, "u_in": "380/50", "phase": "3ф" },
  { "model": "ПЧВ-102-4К0-В", "p_kw": 4.0, "i_nom_a": 9.0, "u_in": "380/50", "phase": "3ф" }
]
```

Поля записи: `model` (номенклатура), `p_kw` (номинальная мощность, кВт),
`i_nom_a` (номинальный выходной ток, А), `u_in` (входное напряжение),
`phase` (число фаз). Дополнительно (необязательно): `brand`, `enclosure`,
`overload_pct` (перегрузочная способность).

### 5.4. Нефункциональные требования

- **Точность.** Частота ±0.1 Гц; мощности — до 1 Вт.
- **Детерминированность.** Одинаковый вход даёт одинаковый результат.
- **Совместимость.** Только `numpy` (+ `Pillow`); без новых зависимостей.
- **Обратная совместимость.** Дроссельный режим и golden-тесты не меняются.

## 6. Расчётная модель

Законы подобия при f = f_Гц / f_ном_Гц:

```
Q_f = f · Q_nom
P_f = f² · P_nom
N_f = f³ · N_nom
η_f(Q_f) = η_nom(Q_f / f)
```

Алгоритм (на вентилятор):
1. k = P_req / Q_req².
2. Q₀:  P_nom(Q₀) = k·Q₀².
3. f = Q_req / Q₀;  f_Гц = f · f_ном_Гц.
4. Проверка: f_min_Гц ≤ f_Гц ≤ f_max_Гц.
5. η_f = η_nom(Q_req / f).
6. N_вал = (Q_req/3600) · P_req / η_f.
7. N_вх = N_вал / (η_ЧРП · η_двиг).
8. n = f · n_nom.
9. **Двигатель** — по N_вал, оборотам, границам карточки (существующая логика).
10. **ЧРП** — по параметрам подобранного двигателя (см. ниже).

### 6.1. Подбор частотного преобразователя

По аналогии с подбором двигателя: из справочника `vfd.json` выбирается ЧРП,
удовлетворяющий параметрам двигателя:

1. `u_in` совпадает с напряжением двигателя (380/50).
2. `p_kw` ≥ мощности двигателя (`motor.n_kw`).
3. `i_nom_a` ≥ номинального тока двигателя (`motor.i_nom`), если ток известен.
4. Выбирается ЧРП с минимальной достаточной мощностью.

Если подходящий ЧРП не найден — отказ со статусом `VFD_NOT_FOUND`.

Примечание: при перекруте (f > 1) допускается требование запаса ЧРП по току
(этап 2 — уточнение перегрузочной способности).

## 7. Контракт обмена (JSON)

**Вход** (`run_selection`):
```json
{ "q_req": 7500, "p_req": 700, "pressure_type": "FULL",
  "regulation_mode": "VFD",
  "freq_min_hz": 30, "freq_max_hz": 60 }
```

**Выход** (поля результата в режиме VFD) — комплект «вентилятор + двигатель + ЧРП»:
```json
{
  "f_hz": 31.0, "n_rpm": 465, "q0": 12100,
  "eta": 0.63,
  "n_shaft_w": 2310.0, "n_in_w": 2800.0,
  "motor": { "name": "160S8", "n_kw": 7.5, "n_rpm": 750, "i_nom": 17.8 },
  "vfd": { "model": "ПЧВ-102-7К5-В", "p_kw": 7.5, "i_nom_a": 18.0 },
  "status": "OK", "passed": true
}
```

Ключевая выдача — **пара «номенклатура вентилятора — частотник»**:
вентилятор `model` + `vfd.model` (и `motor.name` как связующее звено).

Статусы: `OK`, `FREQ_BELOW_MIN`, `FREQ_ABOVE_MAX`, `NO_NETWORK_INTERSECTION`,
`NO_EFFICIENCY_DATA`, `MOTOR_NOT_FOUND`, `VFD_NOT_FOUND`.

## 8. Ограничения и допущения

1. КПД двигателя при частичной нагрузке принят константой (этап 1).
2. Резонансные зоны не учитываются (этап 2).
3. Перекрут — в пределах заданного верхнего диапазона; прочностная проверка — этап 2.
4. Сеть считается чисто квадратичной.
5. Критерий экономии электроэнергии не рассчитывается.
6. Справочник ЧРП наполняется отдельно (начальный набор — в этапе 1).

## 9. Критерии приёмки

1. Для точки (Q=7500, P=700) при диапазоне [30, 60] Гц режим VFD возвращает
   частоту, обороты, КПД, мощности и подобранные двигатель и ЧРП.
2. f корректна по законам подобия (проверка синтетическим кейсом, в т.ч. перекрут).
3. ЧРП подбирается по мощности/току двигателя; при отсутствии — отказ со статусом.
4. Точка вне диапазона частоты — отказ со статусом, а не исключение.
5. Дроссельный режим даёт те же значения (golden-тесты зелёные).
6. Выход соответствует схеме JSON из раздела 7.
