# Кодекс поведения / Code of Conduct

Мы стремимся сделать участие в проекте удобным и безопасным для всех.

## Ожидаемое поведение

- Уважительное и конструктивное общение.
- Критика — по существу и по делу, без личных нападок.
- Готовность объяснять решения и принимать обратную связь.

## Недопустимое поведение

- Оскорбления, троллинг, дискриминация по любому признаку.
- Публикация личных данных без согласия.
- Спам и реклама вне темы.

## Применение

О нарушениях сообщайте владельцу репозитория через GitHub. Нарушители могут
быть предупреждены или заблокированы. Настоящий документ основан на принципах
[Contributor Covenant](https://www.contributor-covenant.org/).
